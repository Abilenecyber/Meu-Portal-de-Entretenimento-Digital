# 🌐 Meu Portal de Entretenimento Digital

Este é um projeto de portal web responsivo que reúne informações e conteúdos sobre **Filmes e Séries**, **Música e Podcasts**, e **Games e Tecnologia**. O projeto foi estruturado utilizando boas práticas de HTML semântico, layouts flexíveis com CSS Flexbox e organização de estilos.

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica do conteúdo.
*   **CSS3:** Estilização, reset de padrões e layout responsivo.
*   **Flexbox:** Alinhamento adaptável das três seções principais.

## 🏗️ Estrutura do Projeto

O repositório está organizado da seguinte forma:

